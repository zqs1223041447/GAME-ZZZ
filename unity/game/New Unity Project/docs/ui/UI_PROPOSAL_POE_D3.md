# UI_PROPOSAL_POE_D3（正式 UI 方案页 · 待导演过目）

日期：2026-09-07。状态：**导演已批准（2026-09-08：正式 UI 开工，本阶段目标=贴图+点击效，声音暂不做）。第 1 轮（底栏+双球+程序化石质贴图+点击效）已落地（规划 AI 已验收）；第 2 轮（右侧装备抽屉：Build/Craft 迁入+常驻 4 槽）已落地**——实现方式与第 4 节建议一致（仍 IMGUI/SliceHud 换皮，未上 UI Toolkit/新 Canvas；贴图=SliceSkin 程序化合成，授权干净；抽屉几何=SliceDrawerLayout 纯几何层）。

## 1. 风格基调（类 PoE / 暗黑 3）

- **深色石质面板**：近黑褐底（参照 #17140F 一带）+ 石纹/凿边质感；面板边缘做暗色倒角，不做圆角玻璃。
- **金色细描边**：1-2px 暗金/铜线勾面板与槽位（Rare 金 #F2C739 及其暗化变体）；描边只在边框，不做大面积渐变。
- **少发光**：仅三类允许微光——Rare+ 物品名、危险预告（地面圈/词缀警示）、可交互高亮 hover。其余全哑光。
- **文字高对比**：米白 #E8DFC8 系正文 + 金色标题；深底上不用灰字。
- **明确不要**：现代扁平（纯色圆角卡片）、赛博 HUD（扫描线/霓虹/半透明蓝）、Q 版圆角。

## 2. 布局草图（ASCII，1920×1080 基准）

```

├─────────────────────────────────────────────────────────────────────┬────────┤
│                                                                     │ 右侧   │
│   （战斗区，无遮挡）                                                  │ 装备栏 │
│                                                                     │ ┌────┐ │
│                                                                     │ │武  │ │
│                                                                     │ ├────┤ │
│                                                                     │ │身  │ │
│                                                                     │ ├────┤ │
│   危险预告：地面圈保持世界内绘制（红/橙），不全屏遮罩                  │ │头  │ │
│                                                                     │ ├────┤ │
│                                                                     │ │饰  │ │

├──────┬──────────────────────────────────────────────────────┬──────┴────────┤
│ 血球 │      Q [支持1][支持2]   W [支持1][支持2]   E [支持1]   │  Support 摘要 │
│ 🔴🔵 │      近战              弹道              范围          │  （小字一行） │
└──────┴──────────────────────────────────────────────────────┴───────────────┘
```

- **血球/蓝球**（左下，PoE 式双球）：生命红球 + 法力蓝球，直径约 110px，液体填充+石质包边；数字叠加球心。现顶部细条升级为球。
- **底栏技能槽**：Q/W/E 三槽居中，每槽=技能名+按键角标+Support 插槽小格（现结构保留，贴皮）。
- **顶栏**：现 topBar 内容（图名/词缀行/锁状态/进出图提示）迁入石牌；Nav 三键（角色/地图/制作）并入顶栏右端。
- **右侧装备抽屉**：装备 4 槽（武器/身体/头/饰）常驻缩略（点击展开完整 Build：背包+天赋树，即现 Build 面板迁入）；**Craft 两步入口**固定在抽屉底部（废料/蚀刻剂计数常显）。
- **Tooltip**：hover 物品=词缀列表（绿色词缀/蓝词缀区分）；Support 兼容性提示沿用现 tip 机制（点到即显，补偿无 Loadout 的对比缺失）。

## 3. 现 SliceHud 块迁移映射

| 现块（SliceHud） | 去向 |
|---|---|
| DrawTop（顶部石牌：状态/图名/提示） | **迁**——顶栏主牌，贴皮重排 |
| DrawNav（右上 角色/地图/制作 三键） | **迁**——并入顶栏右端 |
| DrawBars（生命/法力细条） | **升级**——左下双球（数据绑定不变） |
| DrawSkillHud + DrawSkillCell/Socket（Q/W/E 槽+支持格） | **迁**——底栏贴皮，结构与数据流不动 |
| DrawSupportTray（左下辅助 tray） | **并入**底栏 Support 摘要行（消除左下拥挤） |
| DrawBuild/DrawGearRow/DrawInventory/DrawTree（Tab 面板） | **迁**——右侧装备抽屉展开态（常驻 4 槽缩略新增） |
| DrawCraft（制作面板，废料/蚀刻剂） | **迁**——抽屉底部两步入口+展开面板 |
| Clipped tooltip 机制 | **升级**——词缀对比/兼容提示统一走新 Tooltip 样式（机制保留） |
| 按键路由（Tab/F6/F8/QWE/左键） | **本轮不动**（数据与输入层原样） |
| 无可删块 | 现 HUD 无死块；全部有去向 |

## 4. 分轮实现建议（第 1/2 轮已施工落地，3/4 待规划 AI 安排）

1. **第一轮：底栏+双球**（已完成，R1）——DrawBars→球、SkillHud 贴皮、Support 摘要行。
2. **第二轮：右侧装备抽屉**（已完成，R2）——Build/Craft 面板迁移（右锚于抽屉列左侧，单一渲染器）+常驻 4 槽缩略（只读 canonical EquipSlot，点击=开 Build 面板）。
3. **第三轮：Tooltip 系统升级**（未开始）——词缀对比/兼容提示统一样式。
4. **第四轮（远）**：天赋树界面重排（现 Tree 先原样迁入抽屉）。
- 实现技术：仍 IMGUI（`SliceHud` 内换皮），**不上 UI Toolkit/新 Canvas**；免费石质/金边九宫格贴图可后置（先纯色+描边，贴图后补）。
