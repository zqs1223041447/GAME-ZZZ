# ART_BIBLE（初稿，S3 最小项）

状态：初稿——可执行的约束清单，不是生产任务。**本轮不出新网格、不加内容。**

## 已锁定视觉基线

- 风格：强风格化 + Kitbash；禁止先铺全灰盒再等精模。
- 玩家：Dark Knight（BDO 包）——预制体缩放 0.24，贴地后可见身高 **≈1.19**。
- 怪物视觉高：普通怪 **≈0.58**（`ViewBodyScale=0.58 × EnemyDef.Scale`，Brute/Stinger/Ashling 0.42–0.55 系数）、精英监守 **≈1.17**。
- 相机：拉远读图视角（偏移 (0,10.6,-9.3)、注视斜距 14.1、FOV 42，2026-09-07 按身高 1.19 收一帧）——一切比例以「读图可辨」为准，不以特写为准。

## 角色规则

1. **禁止再埋地**：任何新角色模型挂载必须走 `DarkKnightView.UpdateGround` 身体包围盒贴地路径；身高计算**排除武器**（武器随动画垂地会污染包围盒）。
2. 新角色入库检查：Scale（根节点 1，运行时按 FitToCapsule 归一）、Pivot（脚底在原点）、蒙皮骨骼有效（bones 全非空）。
3. 角色比例带：玩家 1.19 ≈ 精英 1.17 > 普通怪 0.58；新怪按此带设计，避免与玩家混淆。

## 材质 / URP

- 沿用现有 URP/Lit + `MaterialPropertyBlock` 路径；怪视图关阴影（300 只密度红线）。
- 新资源入库检查：命名（小写、下划线分隔、部位前缀）、贴图类型（法线图须 NormalMap 导入）、透明贴图须烘好 alpha（参考 `cloak_t.png`/`lower_t.png` 做法）。
- 材质名与网格部位对应（参考 `DarkKnight/Materials/` 的槽位映射）。
